# Abubakar A. – Portfolio

React + Vite portfolio. No runtime dependencies beyond React.

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/
    npm run preview  # preview the build

## Deploy
Upload `dist/` to Netlify, Vercel, Cloudflare Pages or GitHub Pages. `public/404.html` is copied to the build root and used as the custom 404 page where the host supports it. Contact is via mailto and tel links, so no backend or keys are needed.
